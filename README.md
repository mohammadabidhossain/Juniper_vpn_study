# VPN Mastery: Complete University-Level Course

This repository contains the source code for the "VPN Mastery" website, a project focused on providing comprehensive educational content related to Virtual Private Networks (VPNs). It specifically covers concepts and implementations relevant to Juniper networks.

## Overview

The application is a modern web interface built with HTML, CSS, and JavaScript, designed to present a university-level curriculum on VPNs.

### Features
- **Responsive Design:** Optimized for both desktop and mobile viewing with a collapsible sidebar.
- **Theme Toggling:** Supports both Dark and Light modes for better accessibility.
- **Educational Structure:** Organizes content into structured modules for progressive learning.

## Structure
- `index.html.html`: The main entry point of the application.
- `css/style.css.css`: Stylesheets for visual layout and theme management.
- `js/main.js.js`: Application logic handling interactivity, such as the mobile menu and theme toggles.

## Running Locally
To view the website, you don't need any complex build tools. Simply open the `index.html.html` file in any modern web browser.
